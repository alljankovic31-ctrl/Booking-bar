# Ananasa Tri Demo Bar

A premium mobile-first hospitality demo app built for nightlife venues, bars, and event-based businesses.

The project demonstrates a modern Instagram link-in-bio booking experience with event discovery, VIP booking, guest list flows, and visual table reservation concepts.

## Project Purpose

This repository is a product demo showing how AI-assisted app builders can be used to quickly create operational tools for hospitality and nightlife businesses.

The goal is to demonstrate:

- product thinking
- UI/UX structure
- booking workflow design
- mobile-first experience
- event and reservation flows
- AI-assisted product development
- fast prototype execution

## Core Features

- Landing page for Instagram traffic
- Event overview
- Table reservation flow
- VIP booking concept
- Guest list flow
- Contact and inquiry structure
- Admin-oriented content structure
- Premium dark visual design

## Built With

- Base44
- React
- Tailwind CSS
- Vite
- AI-assisted product development workflow

## Use Case

This type of app can be used by:

- bars
- clubs
- event venues
- restaurants
- hospitality brands
- Instagram-driven businesses

## Why This Matters

Small hospitality businesses often rely on fragmented tools, manual messages, and social media DMs for reservations.

This demo shows how a lightweight digital product can create a more structured booking and customer experience.
